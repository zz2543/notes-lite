# 08: 图片与附件：完成图文资料记录

**What to build:** 向笔记加入本地图片与附件，写入可解析引用，显示图片并打开附件。

**Blocked by:** 04：Markdown 原地排版与源码编辑

**Status:** ready-for-agent

- [ ] 通过实际界面加入图片和一般附件，并在笔记库中产生预期文件与本地 Markdown 引用。
- [ ] 图片可见、附件可打开；切换源码、保存和重开后引用仍有效。
- [ ] 同名附件不会被静默覆盖；中文名称和相对路径样例可用。
- [ ] 文件缺失、不可读或导入失败时有反馈，不产生虚假成功状态或破坏正文。
- [ ] 编辑、滚动与图片显示不使选区或中文输入失效；文件生成和实际打开结果均纳入验收。
