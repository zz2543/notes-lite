# 10: 整页专注模式：进入、写作、返回

**What to build:** 从 B 三栏进入只呈现笔记标题与正文的专注模式，继续编辑保存，再返回原来的资料库位置。

**Blocked by:** 02：B 三栏资料库：浏览文件夹与笔记；04：Markdown 原地排版与源码编辑

**Status:** ready-for-agent

- [ ] 进入后隐藏文件夹、笔记列表、应用工具栏、元信息和状态栏，保留标题、正文与低显著度退出入口。
- [ ] 退出入口和 Esc 均能返回 B 三栏，恢复原选择、光标、选区及阅读位置。
- [ ] 专注模式中标题与正文可正常编辑、撤销和自动保存；退出、保存及重开后正文一致。
- [ ] 专注模式与普通布局使用同一文档，不创建编辑副本，不因重建编辑器丢失中文组合输入或未保存内容。
- [ ] 快速进入和退出不锁定操作、不显示错误笔记；本任务先验证完整状态切换，复杂转场由后续任务交付。
