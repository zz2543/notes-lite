# 15: 列表与段落之间的空行压矮显示

**What to build:** 打开或编辑任何笔记时，紧接在列表项之后、又紧挨着普通段落的那一个空行以极小行高显示，仅保留段落已有的间距，使列表与随后正文在视觉上不被多出的一行隔开。源码保持不变。完整决定见 [退出列表与空行插入光标规格](../../../design/notes-lite/list-exit-caret-spec.md)。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] “列表项、单个空行、普通段落”中的空行以极小行高显示，段落相对列表的纵向位置与“列表项、段落”紧邻时一致（仅保留段落间距）。
- [ ] 无序、有序、任务列表之后均适用；打开已有笔记同样生效。
- [ ] 列表与段落之间有两个及以上空行时全部按正常空行显示；列表与列表、段落与段落之间的空行不受影响。
- [ ] 代码块等字面块内的空行不受影响；源码视图与保存的 Markdown 不变。
- [ ] 在真实原生编辑器测试中断言行的纵向位置，修复前失败、修复后通过。
