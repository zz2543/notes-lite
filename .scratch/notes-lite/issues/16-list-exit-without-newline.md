# 16: 最外层空项退出列表不换行

**What to build:** 在最外层空列表项上回车只退出列表、不另起新行；在这一行开始输入正文时自动补分隔空行，使保存的 Markdown 在其他编辑器中依然正确，并且输入时文字零位移。完整决定见 [退出列表与空行插入光标规格](../../../design/notes-lite/list-exit-caret-spec.md)。

**Blocked by:** 15：列表与段落之间的空行压矮显示

**Status:** ready-for-agent

- [ ] 无序、有序、任务列表的最外层空项回车只移除标记（含缩进），光标留在原行行首，不换行。
- [ ] 该行开始输入（键入、输入法开始组字、粘贴非空内容）时在其前补入分隔空行，保存后源码为“列表项、空行、正文”；只移开光标或保持为空则不补。
- [ ] 该行开头构成完整列表标记（含空格）或被删空时撤回分隔空行；只有 `-` 时不撤回。
- [ ] 补入与撤回分隔空行和触发输入处于同一撤销分组；其余沿用系统撤销粒度，连续撤销可逐步回到退出前。
- [ ] 退出后在这一行打第一个字或开始组字时，该行文字与插入光标不发生纵向位移。
- [ ] 代码块等字面块内不触发；保留退出后忽略输入法立即回显列表标记的保护。
- [ ] 在真实原生编辑器测试中覆盖上述行为与保存后的源码；现有 `- 项目\n\n` 断言改写为新行为，修复前失败、修复后通过。
