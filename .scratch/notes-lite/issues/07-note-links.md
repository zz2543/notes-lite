# 07: 笔记链接：连接并跳转相关内容

**What to build:** 在正文中创建本地笔记链接，并通过实际界面打开相关笔记。

**Blocked by:** 02：B 三栏资料库：浏览文件夹与笔记；04：Markdown 原地排版与源码编辑

**Status:** ready-for-agent

- [ ] 可输入并识别笔记链接，从原地排版中跳转到正确本地目标。
- [ ] 跳转后导航选择与正在编辑的文档一致，不丢失原笔记已输入内容。
- [ ] 目标不存在或名称存在歧义时有明确反馈，不任意跳转到错误文档。
- [ ] 链接在源码切换、保存和重新打开后保持原义，中文名称和子文件夹样例可用。
- [ ] 在临时笔记库中验证创建链接、跳转和重开完整流程，为后续改名、移动后的引用维护提供可检查样例。
