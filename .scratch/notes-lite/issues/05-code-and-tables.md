# 05: 代码块与表格：完成结构化笔记

**What to build:** 在同一篇笔记中书写、修改并显示代码块和表格，保留可编辑的原始 Markdown。

**Blocked by:** 04：Markdown 原地排版与源码编辑

**Status:** ready-for-agent

- [ ] 代码围栏、语言标记及代码正文正确显示；代码中的 Markdown 符号不被误判为普通排版。
- [ ] 表格头、对齐和单元格显示可读；包含中文、空单元格及转义分隔符样例。
- [ ] 源码与原地排版切换后内容一致；编辑表格或代码时中文输入、选区与撤销可用。
- [ ] 长代码行或较宽表格不使正文不可编辑；不以静态预览替代实际编辑能力。
- [ ] 临时笔记库内完成输入、修改、保存和重开，辅以适用的既有表格、代码与语法边缘测试。
