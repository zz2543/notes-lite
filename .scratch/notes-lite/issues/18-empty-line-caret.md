# 18: 空行插入光标对齐

**What to build:** 空行上的插入光标与在该行打出第一个字之后的位置和高度完全一致，开始输入时光标零位移。完整决定见 [退出列表与空行插入光标规格](../../../design/notes-lite/list-exit-caret-spec.md)。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 段落之间的空行：光标纵向位置与高度与打出第一个字后的光标在 0.6 点内一致。
- [ ] 文档末尾的空行：同上。
- [ ] 空行上开始输入法组字时光标不发生纵向位移。
- [ ] 光标高度不因行距被拉长，水平位置仍取自 AppKit。
- [ ] 在真实原生编辑器测试中覆盖上述场景，修复前失败、修复后通过。

## Comments

“刚退出列表后的那一行”的零位移由 16 验收。
