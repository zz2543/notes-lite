# 17: 嵌套空列表项逐级退出

**What to build:** 在嵌套的空列表项上回车时退回上一层级，而不是直接结束整个列表；缩进与标记跟随父项。完整决定见 [退出列表与空行插入光标规格](../../../design/notes-lite/list-exit-caret-spec.md)。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 嵌套空项回车后缩进与父项对齐，光标位于新标记之后，不新增行。
- [ ] 标记跟随父项类型：无序沿用父项符号；有序为父项编号加一并沿用父项分隔符；任务父项生成未勾选任务标记。
- [ ] 后续同级项不重新编号；退一级不补分隔空行。
- [ ] 多层嵌套逐次回车逐级退出，到达最外层后按退出列表规则处理。
- [ ] 撤销可恢复退一级前的状态。
- [ ] 在真实原生编辑器测试中覆盖三种列表类型与保存后的源码，修复前失败、修复后通过。

## Comments

与 16 修改同一换行处理入口，二者逻辑独立；并行实施时需在合并时处理冲突。
