# 03: 搜索与最近打开：快速返回内容

**What to build:** 从三栏界面搜索标题与正文并打开结果，使用最近打开列表返回处理过的笔记。

**Blocked by:** 02：B 三栏资料库：浏览文件夹与笔记

**Status:** ready-for-agent

- [ ] 标题与正文均可检索，包含中文样例；结果清楚标识目标笔记。
- [ ] 选择结果后打开正确正文，文件夹、列表和选中项保持一致。
- [ ] 最近打开列表反映真实打开操作，可返回目标笔记；顺序与重启后的保留策略有明确行为。
- [ ] 提供无搜索结果以及目标文件被移走或删除后的反馈，不错误打开另一篇同名笔记。
- [ ] 在应用中演示搜索浮层的打开与关闭，供后续 Metal 效果接入；本任务不要求复杂视觉效果。
- [ ] 搜索和跳转不破坏当前笔记的保存状态，用实际磁盘结果与界面检查完整流程。
