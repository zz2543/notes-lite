# 04: Markdown 原地排版与源码编辑

**What to build:** 直接书写 Markdown 并在当前编辑空间看到基础排版，能够查看和编辑同一文档的源码。

**Blocked by:** 01：独立应用：完成一次笔记写作闭环

**Status:** ready-for-agent

**Progress:** completed

- [x] 在真实 AppKit 编辑器中支持标题、段落、强调、引用和列表的输入与原地显示。
- [x] 排版与源码围绕同一文档工作，不维护会失步的两份正文；切换后保存内容保持 Markdown 保真。
- [x] 中文组合输入、选区、光标、撤销重做与列表输入可用，不被样式更新破坏。
- [x] 切换源码显示或重排时保留合理的编辑位置，不在每次操作后跳回文首。
- [x] 从原产品复用解析或编辑能力时仅接纳纯笔记部分；必要提取先于本任务的功能接入完成。
- [x] 复用适用的既有 Markdown 语法测试，并通过真实输入、保存、重开验证；不为内部调用关系编写镜像测试。
