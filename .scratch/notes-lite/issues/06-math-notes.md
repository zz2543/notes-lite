# 06: 公式：完成数学笔记

**What to build:** 在笔记中编辑并显示行内公式与独立公式，错误公式不妨碍继续写作。

**Blocked by:** 04：Markdown 原地排版与源码编辑

**Status:** ready-for-agent

- [ ] 行内公式与独立公式均可在真实编辑器中输入、显示、修改并保存。
- [ ] 公式中的下划线等标记不被错误解释为普通文本样式，代码区域中的公式符号不误渲染。
- [ ] 不完整或错误公式保留可编辑原文并提供可理解呈现，不阻塞输入或使应用崩溃。
- [ ] 切换源码、撤销修改、保存和重开后公式原文保真，正文阅读与命中区域正常。
- [ ] 检查实际应用中的显示结果，并复用适用的行内、独立公式解析测试；仅解析通过不能代表渲染通过。
