# 09: 整理笔记库：安全改名、移动和删除

**What to build:** 从资料库界面创建文件夹、重命名和移动笔记，维护引用，并以可恢复方式删除。

**Blocked by:** 07：笔记链接：连接并跳转相关内容；08：图片与附件：完成图文资料记录

**Status:** ready-for-agent

- [ ] 创建文件夹、重命名和移动可从真实界面完成，文件位置与三栏显示一致。
- [ ] 重命名和移动后，指向该笔记的已支持链接仍能跳转，笔记中的相对图片及附件引用仍可使用。
- [ ] 名称冲突与非法名称得到反馈，不覆盖既有笔记或附件，不产生部分成功却显示全成功的状态。
- [ ] 删除采用可恢复方式，演示删除与恢复后正文可重新打开。
- [ ] 整理当前编辑笔记时保留用户内容与正确选择；最近打开或搜索遇到旧位置时不打开错误对象。
- [ ] 记录临时笔记库前后的实际文件变化，旧协作元数据保持不动；测试跨文件夹整理及引用的最终用户行为。
