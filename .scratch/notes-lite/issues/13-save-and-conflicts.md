# 13: 保存异常与外部修改：保护未保存内容

**What to build:** 遇到保存失败、离开未保存笔记或外部文件修改时，用户能够理解状态并保留自己的内容。

**Blocked by:** 01：独立应用：完成一次笔记写作闭环

**Status:** ready-for-agent

- [ ] 在临时笔记库模拟不可写或写入失败，界面不显示保存成功，用户输入仍可恢复或另存。
- [ ] 切换笔记、关闭窗口和退出应用时明确处理未保存内容，不能静默丢弃。
- [ ] 从外部修改当前文件后，应用识别冲突或变化；不静默覆盖用户未保存正文或外部新内容。
- [ ] 提供可执行的重试、保留或选择处理路径；具体界面可由实现确定，最终磁盘与保留内容可核验。
- [ ] 恢复可写状态或完成冲突处理后，可继续保存、关闭并重开，内容与用户选择一致。
- [ ] 测试通过真实应用和外部文件操作完成，不仅模拟内部保存方法；不在真实用户笔记库中注入故障。
