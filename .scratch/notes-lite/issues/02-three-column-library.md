# 02: B 三栏资料库：浏览文件夹与笔记

**What to build:** 在新应用中通过文件夹、笔记列表、正文三栏浏览本地资料，随时明确当前正在编辑的笔记。

**Blocked by:** 01：独立应用：完成一次笔记写作闭环

**Status:** ready-for-agent

**Progress:** in-progress

- [ ] 默认呈现已选定的 B 布局，不包含原型方案选择条或 Agent 面板。
- [ ] 选择文件夹后列表显示对应笔记；选择笔记后正文、选中状态和实际文件一致。
- [ ] 空笔记库、空文件夹、不可读笔记或失效选择均有可理解的状态，不误显示其他文档。
- [ ] 调整窗口宽度后仍可访问导航并编辑正文；记录本次确定的最小宽度和栏宽策略，不机械继承原产品尺寸。
- [ ] 在临时笔记库中演示跨文件夹切换、编辑与保存，验证已保存正文未因导航变化丢失。
