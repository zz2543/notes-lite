# 02: 新建空间并在空间模式里浏览

**What to build:** 用户在侧栏顶部切换「资料库 | 空间」，新建一个空间（名称、emoji、范围：一个/多个文件夹或整个笔记库），在空间模式下浏览范围内的笔记；空间还没有主页时，可以一键复制给外部 Agent 的提示词。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 侧栏顶部「资料库 | 空间」切换；资料库模式行为与现在完全一致。
- [ ] 新建空间生成 `.留白/空间/<名称>.html`，`lb-scope` 与图标写在 meta 中，正文为空；名称冲突和非法名称有反馈。
- [ ] 空间模式左栏列出空间（emoji + 名称）和「新建空间」；中栏是范围内的文件夹和文件树，顶部固定「主页」；范围为整个库时等同资料库树。
- [ ] 中栏点击笔记，右栏打开正常编辑器；点「主页」回到空间主页区域。
- [ ] 空间文件正文为空时，右栏显示「让 agent 生成主页」；新建后和点击该按钮时，把提示词复制到剪贴板，内容包括编写说明路径、空间文件路径、名称、范围，以及范围内现有记录表的位置和表头。
- [ ] 留白生成初版 `.留白/空间/编写说明.md`（文件格式与 meta、记录表格式、必须遵守的规则），版本升级时自动覆盖。
- [ ] 同一文件夹可以出现在多个空间的范围中；`.留白/` 不出现在资料库的笔记列表和搜索中。
- [ ] 以临时笔记库测试空间文件与提示词内容；以真实窗口检查模式切换和导航。
