# 01: 持续文件监听：外部修改即时可见

**What to build:** 外部工具（外部 Agent、其他编辑器、Finder）在笔记库里新建、修改、删除笔记后，资料库导航、笔记列表和编辑器无需重新激活应用就自动反映变化；扫描笔记库不再阻塞主线程。这是空间主页实时刷新的基础（铺垫重构）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Progress:** completed

- [x] 应用保持在前台时，外部新建、修改、删除笔记会在短时间内反映到资料库导航和笔记列表；实测延迟记录在 evidence 中。
- [x] 当前编辑的笔记被外部修改时，沿用现有保存冲突的处理，不静默覆盖未保存内容。
- [x] 笔记库扫描在后台按修改时间增量更新，打开大库时主线程不被全量读取阻塞（记录实测库规模和测量方式）。
- [x] 监听提供可订阅的变化通知（路径级），供后续空间主页使用；`.留白/` 下的变化也能被订阅，但不出现在笔记列表和搜索里。
- [x] 以临时笔记库测试外部修改后的可见状态，沿用 Workspace 测试的方式。
