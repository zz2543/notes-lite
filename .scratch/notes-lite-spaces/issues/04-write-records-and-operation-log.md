# 04: 写入记录与操作记录

**What to build:** 空间主页的脚本可以无需用户点击地新增、修改、删除范围内的记录；每条被改动的记录都进入持久化的操作记录，用户可以逐条撤销，并会在界面上看到写入提示。

**Blocked by:** 03：空间主页渲染：只读的 lb 接口与实时刷新

**Status:** ready-for-agent

- [ ] `lb.append`、`lb.update`、`lb.remove` 修改记录表，并保留笔记其余内容不变；目标笔记或表不存在时按表头自动新建（支持占位符路径）。
- [ ] 记录的身份标识与匹配规则在实现时确定，并写入编写说明。
- [ ] 操作记录按每条记录保存（一次调用改多条记录就拆成多条），包含操作类型、路径、修改前后内容、时间和来源空间；跨重启保留，30 天后自动清理。
- [ ] 逐条撤销可用；目标在之后被修改时给出可理解的冲突反馈，不静默覆盖。
- [ ] 写入后右栏顶部显示「主页刚修改了 N 条记录 · 查看」，点「查看」打开操作记录面板，可在面板中撤销。
- [ ] 在 lb 请求处理接缝上测试写入、新建表、范围拒绝、撤销、重开笔记库后撤销和到期清理（注入时钟）。
