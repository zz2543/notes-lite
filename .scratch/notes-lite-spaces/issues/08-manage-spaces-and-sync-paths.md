# 08: 空间管理与路径同步

**What to build:** 用户可以整理自己的空间（排序、编辑、删除、查看源文件），并且在整理笔记时，空间不会因为路径变化而失效。

**Blocked by:** 02：新建空间并在空间模式里浏览

**Status:** ready-for-agent

**Progress:** in-progress

- [ ] 左栏拖动调整空间顺序，顺序保存在 `.留白/空间/` 下的配置文件里，重新打开库后保持。
- [x] 可以编辑空间的名称、emoji 和范围。
- [x] 删除空间只删除该空间文件，任何笔记都不受影响。
- [ ] 空间右键菜单「显示源文件」。
- [ ] 文件夹或笔记改名、移动时，同步更新所有空间文件中 `lb-scope` 和组件 `source`/`target` 里的路径。
- [x] 以临时笔记库测试顺序持久化、删除空间不动笔记和路径同步。
