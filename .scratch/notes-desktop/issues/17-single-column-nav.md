本地验证（macOS）：`npm run typecheck` 通过；`npm test` 105 个用例通过（新增 `tests/core/library.test.ts` “tells which subfolders hold notes…”，`settings.test.ts` 默认值含 `navigation: "double"`）；`npm run test:e2e` 56 个用例通过。新增 `tests/e2e/navigation.spec.ts`（4 个）：单栏树先子文件夹后笔记、打开的笔记独占选中底板且底板落定后与行等宽、树中笔记右键重命名后仍选中；单栏就地搜索（搜索框与结果代替树，Esc 恢复，打开结果展开到该笔记）；切换导航模式保留笔记、光标位置（切换后继续输入接在原处）与浏览目录，折叠过的祖先文件夹会重新展开（做过变异检查），重启后仍是单栏。CI 未运行。

实施中的决定：
- 设置字段 `navigation: "double" | "single"`，默认双栏（同旧版），放在“通用”页的“导航”分组，分段控件“双栏 | 单栏”。
- 单栏不另起组件：`FolderTree` 传入 `notes` 时每个文件夹在子文件夹后列出笔记（顺序同笔记列表，最近修改在前），树的名称变为“文件夹与笔记”；只含笔记的文件夹也可展开（核心库新增 `hasNotes`）。选中底板只在打开的笔记上；没有打开的笔记时在浏览的文件夹上。浏览的文件夹仍用实心打开图标。
- 在树里打开笔记会把它所在文件夹设为浏览目录，切回双栏时列表就在那里。切到单栏时展开浏览目录与打开笔记的所有祖先。正文卡片不重建，编辑位置不丢。
- 单栏宽度用已有的 `--single-nav-width`（256px）；侧栏列宽规则改为 `aside.side`：原来的 `.side` 同时命中了选中底板的 `pill side` 类，使侧栏底板固定 216px（双栏下比行宽 16px，单栏下短一截）。
- 切换时栏宽不做动画（直接切换），列宽滑移留给任务 23 动效审查一并决定。

留给后续任务：单栏下“在空间下看到主页与文件”依赖任务 19（打开空间、主页与限定范围的树）；19 合入后在单栏的空间页沿用 `FolderTree` 的 `notes` 即可显示文件。任务 26 助手栏的自动收窄可直接切换 `single` 布局（`LibraryView` 中的 `single` 目前只来自设置）。
