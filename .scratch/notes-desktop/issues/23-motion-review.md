**修改**

- 展开箭头（文件夹树、操作记录与审查卡片的时间线）：原来文件夹箭头直接跳转、时间线箭头用“轻弹”；现在都用“展开”弹簧旋转（`--caret-turn`），连点时从当前角度转回。减弱动态效果下不转、直接到位。
- 右键菜单与列表“…”菜单：原来没有入场；现在从指针所在的位置、缩放 0.96（强）展开并淡入（`@starting-style` + CSS 过渡，可打断）；位置按未缩放的尺寸计算。关闭立即消失：设计规范没有规定菜单的退出，见待决定 5。
- 对话框（新建、重命名、移动、空间、操作记录）：原来没有入场；现在与设置面板一样以“浮现”从缩放、上移、模糊进入，罩层淡入；关闭时按“浮层进入”的退出（0.16s 缩小、模糊）离开，离开期间不可操作（inert），不会被重复提交。
- 卡片顶部操作按钮（笔记卡片的“Markdown 源码”）：设计规范要求“悬停时以浮现出现，开始打字即隐藏”（任务 08 留下）。现在悬停在卡片顶部栏时上移 3px 淡入（规格：“鼠标悬停顶部区域时浮现”），按下会输入的键（字符、删除、回车、输入法）后隐藏，方向键、Esc、快捷键不隐藏，指针一动再出现；专注模式下一直隐藏；处于打开状态或有键盘焦点时一直显示；没有悬停能力的指针下一直显示。空间主页卡片的“操作记录”按钮保持常显（主页内容是另一个页面，悬停传不到应用）。
- 透明度不再跟弹簧：与弹簧同行的淡入淡出用 `ease-out` + 预设 visualDuration。Motion 那边在 `shared/motion.ts` 的预设里统一给 opacity 配 ease-out（设置面板、对话框、空间主页卡片等一起生效）；CSS 用新变量 `--fade-<预设>`。CSS 里的位移与缩放按强度乘幅度（`--motion-amplitude`），标准档的取值写在 `shared/motion.ts`（`menuEnter`、`travel.cardToolRise`、`travel.noticeRise`），由 MotionProvider 写入。
- 文件夹行的悬停新建图标（任务 04 留下）：原来透明度瞬间切换；现在随悬停以 `ease-out` 淡入淡出。
- 保存冲突提示（任务 05 留下）：原来没有入场；现在以“浮现”从上方 3px（强）淡入。确认框是系统对话框，不在应用内做动效。
- 助手形象（任务 26 留下的耗电问题）：核对后没有修改。栏内的形象只在助手栏打开时挂载；栏关上时，卡片顶部栏 22px 开关里的形象可见，并持续逐帧绘制（任务 26 要求“持续在动”）。窗口进入后台时 Chromium 已暂停逐帧。是否降低空闲时的帧率，见待决定 6。
- 任务 15、16、20、21 新增的变量（`--settings-*`、`--space-problem` 等）：已核对，都是颜色与尺寸；设置面板内的过渡都已使用“轻弹”预设，不需要修改。
- 设计规范“动效”一节补入以上取值与规则。

**测试**：逐帧采样工具 `film` 移到 `tests/e2e/fixtures.ts` 共用。`design-system.spec.ts`：箭头弹簧与连点终态；新建图标淡入；菜单从角落展开、对话框浮现（逐帧，透明度不回弹）、出现即可输入、Esc 后缩小离开；减弱动态效果的用例补上箭头不转、菜单/对话框不缩放不模糊、但仍淡入。`editing.spec.ts`：卡片按钮悬停顶部栏出现、方向键不隐藏、打字隐藏、打开状态常显。`interruption.spec.ts`：快速连续切换笔记、⌘J 连按、设置开关再开、专注模式进出后终态正确。

**emil 清单逐项结论**

| 界面 | 结论 |
| --- | --- |
| 选中底板（侧栏、列表、分段控件、资料库/空间切换） | 通过：滑移弹簧、layoutId 可打断；减弱动态效果下直接到位 |
| 悬停与按压 | 通过：悬停只变底色，按压缩到 0.97 / 图标 0.89；按下与松开同用轻弹——清单第 9 条希望不对称，但设计规范写明“松开回弹”，保留 |
| 开关、滑块 | 通过：knob 用轻弹 layout 动画 |
| 设置面板 | 通过：浮现入场、0.16s 退出；强档 0.55s 超出清单 300ms 上限，属设计规范取值，保留 |
| 专注模式 | 通过：专注弹簧 + 透明度 ease-out，可中途反向（已有用例） |
| 助手栏开关 | 设计规范写明的例外：栏宽无回弹 0.26s。清单第 7 条会指出“动画 width”；为了栏内容不重排按设计规范保留 |
| 空间主页卡片与组件 | 通过：浮现 + 0.06s 间隔，模糊单独缓动，减弱动态效果只淡入 |
| 展开箭头、菜单、对话框、卡片按钮、新建图标、保存冲突提示 | 已修正，见上 |

| 输入、保存、搜索 | 不等待动画（用例覆盖切换笔记与对话框输入） |

**待决定（设计规范与 emil 清单冲突，或规范未定）**

1. 切换笔记的内容滑移（新内容从 16px 淡入、旧内容 0.1s 反向淡出）：设计规范要求，尚未实现。清单第 2 条：键盘触发、每天上百次的操作不应有动画。
2. 列表行进入 / 退出（上方 6px 淡入 / 缩到 0.96 淡出）：设计规范要求，尚未实现。可以实现：退出中的行设为 `inert`、`aria-hidden`，并立即让出位置。但新建、删除、移动、搜索结果和外部改动都会让行进出，数量多时整列都会动，清单第 2 条（高频操作少动画）对此有疑问。需要确认：是否所有情况都要做，还是只在新建与删除时做。
3. 搜索框展开（展开弹簧）：设计规范要求，尚未实现；搜索由 ⌘K 打开，清单同第 1 项。
4. 导航档位切换的栏宽滑移（任务 17 留下）：档位随窗口宽度变化，拖动窗口时动画会滞后；目前直接切换。
5. 菜单关闭：设计规范没有规定菜单的退出。目前关闭立即消失（清单：系统回应应即时）。可选做法是与对话框一样以“浮层进入”的退出离开。
6. 助手形象的耗电：卡片顶部栏的 22px 形象持续每帧绘制。可选做法：空闲时降到约 20 帧/秒，或只在状态变化、眨眼和视线跟随时绘制；也可以保持现状。
