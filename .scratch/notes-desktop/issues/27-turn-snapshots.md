# 27: 按轮快照与撤销

**What to build:** 每一轮开始前对整个笔记库做增量快照，一轮的改动可以作为一条操作记录整体撤销或逐篇撤回，包括图片附件。

**Blocked by:** 19

**Status:** ready-for-agent

- [ ] Markdown 与文本存入按内容去重的存储，每轮只检查修改时间与大小
- [ ] 附件：macOS 用 APFS 克隆；Windows 首次后台复制基线；超过约 10GB 时 Windows 只记录元数据并提示
- [ ] 一轮结束后得出改动清单，整轮撤销与逐篇撤回都完全还原
- [ ] 快照保留 30 天自动清理；设置显示占用并可立即清理
- [ ] 按用户真实规模（约一万篇笔记、1GB 附件）实测耗时、内存与磁盘并记录
