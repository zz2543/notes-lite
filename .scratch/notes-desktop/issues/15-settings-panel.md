# 15: 设置面板：层级清晰与可视化控件

**What to build:** 设置是一张浮起的玻璃面板，层级清晰、分组明确；数值项都用滑块等可视化控件调整并立即生效。提供外观、强调色、笔记列表详细程度、动效强度等设置。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 左侧分类、右侧分组，每组有标题与简短说明，项目对齐、间距一致
- [ ] 控件库：带实时数值的滑块、分段控件、色板、开关、带预览的选项；不使用纯文本输入数值
- [ ] 外观（跟随系统/浅色/深色）、强调色（跟随系统与预设色）、笔记列表详细程度（简洁/标准/详细，列表“…”菜单同步）、动效强度（轻/标准/强，默认强）
- [ ] ⌘, / Ctrl+, 打开，Esc 关闭，“浮现”入场
- [ ] 设置持久保存在应用中，不写入笔记库
