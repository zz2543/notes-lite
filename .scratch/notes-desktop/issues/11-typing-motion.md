# 11: 光标与输入动画

**What to build:** 光标在位置之间平滑滑动、闪烁柔和；新输入的字符轻微淡入，拼音组合时也有同样的动画；可在设置中分别关闭。

**Blocked by:** 10, 03

**Status:** ready-for-agent（2026-10-20 用户要求移到最后，届时再问是否做）

- [x] 光标移动平滑、可打断，闪烁为淡入淡出（2026-10-23）
- [ ] 新字符约 100ms 淡入、不位移
- [ ] 拼音组合文本、候选变化与上屏都有一致的动画，且无抖动、错位、丢字（macOS 与 Windows 系统拼音输入法分别验证）
- [ ] “光标动画”“输入动画”两个开关，默认开启；减弱动态效果时强制关闭
- [ ] 参数写入设计规范

## Comments

### 2026-10-20 用户调整

用户把任务 10 移到最后，所有任务完成后再问是否做。本任务的光标滑动与闪烁建立在 10 的自绘光标上，随 10 一起移到最后。

### 2026-10-23 用户确认：先只做平滑光标（Notion AI）

用户要求现在只做光标平滑滑动，仿 Word 的平滑光标；字符淡入、工单 10 的光标高度校准与选区贴合都不做。经 grill 确认：
- “拼音待选区”指正文里带下划线的组合文本，候选窗由系统绘制，不动。
- 所有移动都滑（打字、删除、方向键、点击、拼音组合与上屏、换行斜滑）；跨度超过可见高度直接跳。0.12s ease-out、可打断，是“滑移”预设的例外。
- 闪烁改为淡入淡出，移动时常亮，停 0.65s 后开始闪。
- 设置 › 动画 加“光标动画”开关，默认开；关闭即恢复原来的浏览器光标；减弱动态效果时强制关闭。“输入动画”开关等做字符淡入时再加。
- 自动化测试覆盖英文、拼音组合、上屏与开关；macOS / Windows 系统拼音的实际手感由用户在真机上确认。

实现：`src/renderer/src/smoothCaret.ts`（CodeMirror 插件，自绘光标层），参数 `shared/motion.ts` 的 `caretMotion`，测试 `tests/e2e/caret.spec.ts`。
