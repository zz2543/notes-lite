# 11: 光标与输入动画

**What to build:** 光标在位置之间平滑滑动、闪烁柔和；新输入的字符轻微淡入，拼音组合时也有同样的动画；可在设置中分别关闭。

**Blocked by:** 10, 03

**Status:** ready-for-agent

- [ ] 光标移动平滑、可打断，闪烁为淡入淡出
- [ ] 新字符约 100ms 淡入、不位移
- [ ] 拼音组合文本、候选变化与上屏都有一致的动画，且无抖动、错位、丢字（macOS 与 Windows 系统拼音输入法分别验证）
- [ ] “光标动画”“输入动画”两个开关，默认开启；减弱动态效果时强制关闭
- [ ] 参数写入设计规范
