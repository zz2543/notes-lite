- [x] 写入失败时提示，状态不显示已保存，保留输入可重试
- [x] 切换笔记、关闭窗口、退出前保存未保存内容

### 2026-10-19 实施记录

提交：`ae90b3d` 核心库保存、`caaf7d1` CodeMirror 编辑与自动保存、`9b88c9c` 与 `6c55358` 审查修复（标准与规格两轴审查后的修正）。

本地验证（macOS，Apple Silicon）：类型检查通过，且每个提交单独通过类型检查；接缝 A 14 个 Vitest 用例；接缝 B 6 个 Playwright 用例。覆盖：
- 逐字保存：CRLF 笔记仍为 CRLF；粘贴的 `\n` 换行随笔记换行符转换。
- 拼音组合输入、撤销与重做；字数显示。
- 切换笔记、切换笔记库、关闭窗口、退出应用前都会保存。
- 写入被拒绝时显示原因，不显示“已保存”；保留输入，阻止切换；可重试。
- 保存失败后关闭窗口会先询问，选“返回”保留输入，选“不保存”不改动磁盘。
- 磁盘上的笔记已在别处修改时不覆盖。
- 非 UTF-8 笔记拒绝打开，不会被保存损坏。
- 保存保留文件权限。

另做了一次变异检查：去掉关闭前的保存握手后，对应用例失败。

实施中的决定：
- 自动保存在停止输入 450 ms 后进行（同旧版），输入法组合中等待提交，关闭时强制保存。
- 保存经隐藏临时文件替换，保留权限但不保留扩展属性（如 Finder 标签），与旧版原子写入一致。
- 字数按旧版 `NotesCore` 移植：跳过块标记，中文按字，英文与数字按词，“3,200”“50%”算一个。
- 编辑器状态（未保存输入与保存状态）放在界面进程的 `NoteDraft`，核心库只负责“按预期内容写入或拒绝”。

留给后续任务：
- 保存冲突的处理入口（重新载入、另存副本）在任务 05 实现。在此之前，冲突状态不提供“重试”，也会阻止切换笔记。
- 插入光标和选区的强调色只是临时样式，由任务 10/11 重做。

### 2026-10-19 CI 验证
