# 07: 启动性能达标

**What to build:** 打开软件不用等：冷启动 1 秒内能在上次的笔记里打字，再次打开 0.3 秒内恢复，且没有白屏或转圈。

**Blocked by:** 01, 06

**Status:** ready-for-agent

- [ ] 在 Apple M4、约一万篇笔记的笔记库上：冷启动到可输入 ≤ 1 秒；关闭窗口后再次打开 ≤ 0.3 秒
- [ ] 启动不做全库扫描或建索引，先显示上次的笔记与当前目录
- [ ] 窗口出现时无白屏、无转圈启动画面
- [ ] 提供可重复的测量脚本并记录机器、系统、笔记库规模与结果；Windows 数据仅记录作参考
