# Plume · 让想法，落在自己的纸上

原创中文产品宣传短片，42 秒，1920 × 1080，16:9，30 fps。H.264 视频与 AAC 立体声，支持流式起播。中文文案嵌入画面，配原创程序合成音乐，无旁白。

## 交付文件

- `Plume-让想法落在自己的纸上.mp4`：成片。
- `cover.jpg`：封面。
- `storyboard.jpg`：七个场景的分镜总览。
- `scene-01.jpg` 至 `scene-07.jpg`：各场景关键帧。
- `original-score.wav`：为本片合成的独立音乐轨。
- `captions.srt`：可选的无障碍字幕。
- `render.py`：完整可复现的图形、动画、音乐与编码源文件。
- `preview.html`：本地视频播放器。

## 创作说明

从产品 Swift 源码与产品 HTML 原型了解功能，独立完成主题、文案、构图、动画和配乐。未打开或使用仓库 `promo/` 内的宣传视频、脚本、画面或素材。没有调用第三方视频、图片或音乐素材。

本片使用原创绘制的产品界面示意，不是运行中应用的屏幕实录。相应场景在画面中有标注。羽毛图形是本片的原创装饰，不代表已确认的应用图标。AI 内容为演示文案。

宣传点对应以下现有代码：

- 本地 Markdown：`Vault.swift`、`Onboarding.swift`。
- Claude Code / Codex 与共享上下文：`Onboarding.swift`、`MainWindow.swift`、`Theme.swift`。
- 审阅、接受与还原：`ReviewView.swift`。片中未声称 AI 改动必须接受后才会写入磁盘。
- 专注写作、段落聚焦：`Onboarding.swift`、`NoteDetail.swift`。

## 分镜

| 时间 | 内容 | 动效 |
| --- | --- | --- |
| 00–06 秒 | 好想法，值得有个好归处。 | 四张散页浮动，标题分层出现 |
| 06–12 秒 | 落笔，就进入心流。 | 编辑窗进入、逐字输入、光标闪动 |
| 12–18 秒 | 笔记在本地。灵感属于你。 | 深绿底，Markdown 文件卡片依次滑入 |
| 18–24 秒 | 让 AI 接住你的下一句。 | 输入请求、输出示例、更新提示 |
| 24–30 秒 | AI 可以改。决定权在你。 | 增删对比、光标移动、点击接受 |
| 30–36 秒 | 把世界调轻。 | 非当前段落淡出，当前行逐字出现 |
| 36–42 秒 | Plume · 让想法，落在自己的纸上。 | 羽毛、品牌字与收尾文案，音乐渐弱 |

## 重新渲染

macOS 上使用 Python 3、Pillow、NumPy 与 PATH 中的 FFmpeg：

```sh
python3 render.py          # 输出完整视频、音乐和关键帧
python3 render.py --stills # 仅输出关键帧与封面
```

字体使用系统 STHeiti、Georgia 和 Menlo，字体文件未打包分发。其他系统可在 `font()` 中替换字体路径。视频本身不依赖字体安装。
