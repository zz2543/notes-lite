# 以 Electron 单一代码库重写为跨平台桌面版，完全取代 macOS 原生版

状态：已确认。日期：2026-10-19。取代 [0001](0001-independent-native-notes-app.md) 中“macOS 原生、跨平台首版不属于范围”的部分；0001 关于独立于原产品的决定继续有效。

用户希望笔记软件能跨平台使用，并把它视为一个全新版本（另起新名称）。可选做法有：保留 macOS 原生版、其他平台另做客户端；共享核心逻辑、各平台原生界面；或用一套跨平台技术栈完全重写。用户选择完全重写：各平台用同一套代码，功能保持一致，现有 SwiftUI / AppKit / Metal 实现退役。

技术栈在 Electron、Tauri 2 与 Flutter 之间比较后选择 Electron + TypeScript。空间主页是 Agent 自由编写的 HTML，Electron 在各平台都使用 Chromium，同一份编写说明在各平台效果一致；Tauri 依赖各系统 WebView，表现会分叉；Flutter 缺少成熟的 Markdown 原地排版编辑器，且仍需嵌入 WebView。代价是安装包与内存更大。

平台优先级：macOS 为主，Windows 为辅，Linux 暂不考虑；移动端以后再考虑。现有规格（含空间规格、列表退出与光标规格）是新版本的验收基线，达到功能对齐后才取代旧版。Metal 折射等柔软流动效果不是必须项，可降级为半透明模糊材质与弹簧转场。

新版在仓库根目录下作为完整、自包含的独立目录开发，不依赖仓库其他目录，可以整体移出成为独立项目。

笔记库格式保持通用：同一个文件夹在任何平台、任何版本都能打开，现有笔记库无需迁移，只迁移代码。新版不做同步，由用户自选文件同步工具；暂不针对 iCloud Drive 做专门优化，以后再考虑。

笔记库中应用自用的隐藏目录由 `.留白/` 改为与品牌无关的 `.notes/`，以后改名不再触及笔记库。首次打开含 `.留白/` 的笔记库时，自动把其中的空间主页、编写说明和操作记录搬入 `.notes/`；用户的 Markdown 不做任何改动。产品新名称待定，开发期间使用中性代号 `notes-desktop`。

同理，空间主页的页面接口、组件、样式变量与 meta 改用与品牌无关的前缀，原 `lb` 系列名称保留为兼容别名，已有空间主页无需修改即可运行。
