# 新版内置右侧 Agent 侧栏，通过外部命令行 Agent 运行

状态：已确认。日期：2026-10-19。修订 [0002](0002-space-pages-written-by-external-agents.md) 中“留白暂不内置 Agent”，以及 [0001](0001-independent-native-notes-app.md) 与基线规格中“不继承 Agent 运行”的排除。

用户希望在新版主窗口右侧加入 Agent 侧栏，与笔记互动。可选做法有：调用外部命令行 Agent（Claude Code、Codex 等）；应用内直接调用模型接口、由核心库实现受限工具；或两者都做。用户选择调用外部命令行 Agent（Claude Code、Codex、DeepSeek Harness、Pi）：可以直接使用用户已有的订阅和这些 Agent 的完整能力。代价是重新引入命令行检测、会话管理和进程控制，Windows 上的安装与路径也更脆弱。

用户明确不限制 Agent 的权限，不沿用空间主页那种“只能访问范围内”的约束（0003 仍只约束空间主页）。为减少反复确认，对笔记写入的审查可在设置中调整，且审查粒度要粗，不逐条让用户点同意。外部 Agent 直接改写磁盘，所以审查只能发生在改动之后：每一轮开始前对整个笔记库做增量快照，一轮的改动作为一个整体审查（默认）或直接保留，并可整体撤销。详见 [助手栏规格](../specs/assistant-spec.md)。

0002 要求以后加入 Agent 侧栏时复用同一份编写说明与接口：Agent 编写空间主页时仍以编写说明为准。

侧栏作为可折叠的第四栏，放在里程碑 5（新版取代旧版之后）实现；布局与 Agent 图标现在设计，主窗口预留位置。
