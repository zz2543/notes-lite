# 空间主页由外部 Agent 编写，留白暂不内置 Agent

状态：已确认，“暂不内置 Agent”部分被 [0005](0005-agent-sidebar-via-external-cli.md) 修订。日期：2026-10-18。修订 0001 及规格 Out of Scope 中“生成式工作区”一项。

用户希望为健身、雅思等主题提供可按个人场景定制的空间主页，由 Agent 生成。可选做法是在留白内置 Agent 面板，或让外部 Agent（Claude Code、Codex 等）按留白提供的编写说明直接写空间主页文件。内置面板会重新引入会话、CLI 检测与审阅等原产品能力，且交互尚未打磨，因此首版选择后者：留白只提供空间主页文件格式、编写说明与受限接口，不运行 Agent。

空间主页数据仍以范围内的 Markdown 笔记为准，空间主页本身不保存数据。用户计划之后加入 Agent 侧栏；届时应复用同一份编写说明与接口，而不是另建一套生成通道。
