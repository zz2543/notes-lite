# 空间主页在范围内拥有完整读写权限，并允许联网

状态：已确认。日期：2026-10-18。

用户希望空间主页的能力足够大，可由 Agent 按个人场景自由定制。可选做法有：只允许用户点击触发的追加写入；在范围内开放完整读写；开放整个笔记库或库外文件与命令。最终选择范围内完整读写：空间主页可以新建、修改、删除记录，也可以新建、改名、移动、删除范围内的笔记，且脚本无需用户点击即可写入；范围外不可访问，需要全库时把范围设为整个笔记库。空间主页允许联网，可引用网络资源和拉取外部数据。

代价是 Agent 编写的脚本出错时影响更大。对应的护栏是：每次写入都进入可跨重启撤销的操作记录，删除笔记一律进入废纸篓，写入后在界面上提示；联网获得的数据必须写入记录表，不能只留在页面内，以保持 Markdown 为唯一数据来源。
