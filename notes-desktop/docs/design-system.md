# 设计规范

日期：2026-10-19。状态：已定稿，取值来自用户选定的原型（原生材质版，默认动效强度“强”）。规则来源：[界面与动效规格](specs/ui-motion-spec.md)。原型代码已从工作分支移除，完整保留在分支 `prototype/notes-desktop-ui`（提交 `3ec2a37`）的 `notes-desktop/prototype/` 中，可随时找回对照。

## 动效

### 预设

所有动效只用这四种弹簧预设（Motion 的 `visualDuration` + `bounce` 写法）。默认强度为“强”：

| 预设 | 强（默认） | 标准 | 轻 | 用于 |
| --- | --- | --- | --- | --- |
| 轻弹 | 0.19s / 0.32 | 0.18s / 0.28 | 0.15s / 0.10 | 悬停、按压、开关、图标线性变实心 |
| 滑移 | 0.32s / 0.18 | 0.30s / 0.16 | 0.26s / 0.06 | 选中底板、列表增删与重排、切换笔记的内容、栏宽、插入光标 |
| 展开 | 0.42s / 0.57 | 0.32s / 0.22 | 0.27s / 0.08 | 文件夹展开、箭头旋转、菜单、搜索框展开、空间主页图表 |
| 浮现 | 0.55s / 0.68 | 0.42s / 0.26 | 0.36s / 0.09 | 对话框、设置面板、空间主页卡片入场与切换 |

专注模式的整卡展开不用“浮现”，而用更克制的**专注**弹簧：强 0.46s / 0.12，标准 0.42s / 0.08，轻 0.36s / 0.03；回弹最多 0.12。侧栏与笔记列表同时淡出，只左移 4–6px。这些淡出（以及专注模式压暗背景的淡入淡出）是有意不用弹簧的：透明度用 `ease-out` 缓动，时长 `--focus-fade-duration`，因为透明度回弹会让栏目闪一下，减少动态效果时也只剩这段淡入淡出。

强度换算规则：以“标准”为基准，“强”把回弹乘 2.6、时长乘 1.3，“轻”把回弹乘 0.35、时长乘 0.85；轻弹与滑移属于高频动效，回弹最多乘 1.15、时长最多乘 1.05。回弹上限 0.72。

### 幅度

位移与缩放距离按强度乘系数：强 2、标准 1、轻 0.6。下表为“强”档取值：

| 动效 | 取值 |
| --- | --- |
| 切换笔记 | 新内容从移动方向一侧 16px 处淡入；旧内容 0.1s 淡出、反向移 8px |
| “资料库 \| 空间”切换 | 侧栏内容横移 120px 并淡入淡出 |
| 浮层进入 | 从缩放 0.88、上移 20px、模糊 10px 进入；退出 0.16s 到缩放 0.97、模糊 6px |
| 空间主页卡片 | 从下方 28px、缩放 0.92、模糊 6px 依次进入，每张间隔 0.06s |
| 按压 | 缩小到 0.97（图标按钮 0.88–0.9），松开回弹 |
| 列表行进入 / 退出 | 从上方 6px 淡入 / 缩到 0.96 淡出，退出时立即让出位置 |
| 菜单（任务 23） | 从指针所在的角、缩放 0.96 展开并淡入（透明度用 `ease-out`、时长同“展开”）；关闭立即消失（待定） |
| 对话框（任务 23） | 与“浮层进入”相同，含退出；离开期间不可操作，不等动画 |
| 卡片顶部操作按钮（任务 23） | 悬停顶部栏时从下方 3px 以“浮现”淡入 |
| 保存冲突提示（任务 23） | 从上方 3px 以“浮现”淡入 |
| 文件夹行新建图标（任务 23） | 随悬停淡入淡出（`ease-out`，时长同“浮现”） |
| 展开箭头（任务 23） | 旋转 90°（角度不乘幅度），用“展开”弹簧；连点时从当前角度转回 |

### 模糊

`filter: blur()` 不跟随弹簧，单独用缓动 `cubic-bezier(.2,.8,.2,1)`，时长 0.28s × 强度时长系数（“强”为 0.36s），避免回弹时出现负模糊值。

### 规则

- 所有动画可以打断和反向；连续操作时立即中断上一段，不排队。输入、保存、搜索不等待动画。
- 悬停只加 `--hover` 底色，不浮起；卡片、按钮等独立元素可以轻微浮起。
- 卡片顶部操作按钮在悬停顶部栏时以“浮现”出现，开始打字（按下会输入的键）即隐藏。
- 系统开启“减弱动态效果”时，位移、缩放、模糊全部取消，只保留不透明度变化；光标与输入动画关闭。
- 透明度不跟弹簧：与弹簧同行的淡入淡出用 `ease-out`、时长取该预设的 visualDuration（CSS 变量 `--fade-<预设>`），避免回弹让元素闪烁。
- 卡片顶部操作按钮只在能悬停的指针（`(hover: hover) and (pointer: fine)`）下隐藏到悬停；处于打开状态（如“Markdown 源码”）或有键盘焦点的按钮一直显示。专注模式下这些按钮始终隐藏。
- 光标动画与输入动画的参数在 CodeMirror 编辑器原型中另行确定，确定后补入本节。
