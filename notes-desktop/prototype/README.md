# PROTOTYPE · 界面与动效（一次性）

用于回答“新版应该长什么样、怎么动”，定稿后删除，参数写入 `../docs/design-system.md`。规格见 [界面与动效规格](../docs/specs/ui-motion-spec.md)。

运行（仓库根目录）：

```sh
npm --prefix notes-desktop/prototype run dev
```

打开 http://localhost:5288/?variant=A （A 原生材质 / B 渐变磨砂 / C 大胆高饱和）。底部黑色工具条切换变体、动效强度、深浅色和减弱动态效果；不在输入框中时 ← → 也可切换变体。

可试的操作：⌘K 或侧栏搜索按钮就地搜索（Esc 退出）、⌘⇧F 专注模式（Esc 返回）、⌘, 设置（排版页实时预览）、↑↓ 切换笔记、“资料库 | 空间”切换、文件夹展开、列表“…”菜单切换详细程度。示例数据只在内存中。

助手栏（里程碑 5 的设计稿）：⌘J 开关；在输入框回车会按脚本演示一轮（思考 → 搜索 → 读取 → 写入 → 完成）和审查卡片。底部工具条的“形象实验台”可逐个查看助手形象的各状态与粒子融合。
