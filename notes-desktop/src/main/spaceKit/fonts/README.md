# 空间风格字体

风格参考「晴空」「暗夜」「玻璃」「便当」用 Inter，「大地」用 Urbanist，「活力」用 Plus Jakarta Sans。
三款都是可变字体（粗细 100–900），只含拉丁字符；中文落到系统字体。都以 SIL Open Font License 1.1 发布：

- Inter — Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter)
- Plus Jakarta Sans — Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans)
- Urbanist — Copyright 2021 The Urbanist Project Authors (https://github.com/coreyhu/Urbanist)

字体以 base64 文本存放（`*.woff2.b64`），应用在 `/kit/fonts/` 解码提供。
