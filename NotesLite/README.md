# 留白 / NotesLite

独立的本地 Markdown 笔记应用。名称为当前工作名，原有共笔应用及其数据、配置和源码修改保留。

## 构建与启动

需要 macOS 26 或更新版本以及支持 Swift 6.2 包清单的 Xcode 工具链。当前在 macOS 27.0.1、Apple M4 上构建和检查，Swift 语言兼容模式沿用原排版代码的 Swift 5 模式。

```sh
./scripts/bundle.sh
```

打开生成的 `build/NotesLite.app`。首次选择一个本地文件夹作为笔记库；检查时请使用临时目录或资料副本。也可使用 `swift run NotesLite --vault <本地目录>` 启动开发版本，开发资源会由 SwiftPM 提供。

## 已实现的产品能力

- 独立身份与设置，无 Agent、模型调用、自动化、MCP、socket 或 HTTP 控制服务。
- 中性灰白三栏资料库、文件夹浏览、标题/正文搜索、最近打开。
- 原生 AppKit 编辑、自动保存、中文输入、撤销、Markdown 原地排版及源码显示。
- 代码高亮、表格与本地 KaTeX 公式显示；渲染资源随应用分发。
- 笔记链接（⌘点击跳转）、图片与附件导入、图片粘贴及文件拖入。
- 笔记改名、跨文件夹移动及引用更新、移到废纸篓、恢复上次删除。
- 整页专注模式、Esc 返回、编辑选区与阅读位置保持。
- SwiftUI 弹簧转场和真实 Metal 折射材质、边缘高光、短暂波纹；静止后暂停效果刷新。
- 保存错误、外部修改冲突、保留输入、重试和另存副本。

## 常用操作

| 操作 | 入口 |
| --- | --- |
| 打开笔记库 | ⌘O，或侧栏底部 |
| 新建笔记 | ⌘N |
| 保存 | ⌘S（另有自动保存） |
| 搜索 | ⌘K |
| 切换专注 | ⌘⇧F，或右上角按钮；Esc 返回 |
| 切换源码 | ⌘⇧M，或编辑区右上角 |
| 整理笔记 | 列表右上角省略号，或右键菜单 |
| 打开笔记链接 | ⌘点击 |
| 打开嵌入图片 | 双击 |

外部文件变化在应用重新激活和保存前检查。当前不提供跨应用的持续文件监视器；同一笔记被外部修改且本地未保存时，优先保留输入并提示处理。另存副本会在当前笔记库根目录生成独立文件。

## 检查

```sh
swift test
```

测试覆盖真实临时笔记库和原生编辑器，原生界面测试需要可用的 macOS 桌面会话。源码改名引用更新还验证代码示例不被误改。首个可运行版本尚未宣告完整验收通过。具体实测条件、通过项、限制和证据见 `evidence/verification.md`，不能把构建成功当作完整体验验收。

Debug 版本将 Metal 设备、管线、实际绘制次数及暂停状态记录在本机独立缓存的 `metal-debug.json`，用于验证真实渲染路径；不发送网络遥测。帧回调间隔不是 GPU 帧耗时。Release 不写这份调试记录。

## 代码来源

Markdown 解析、字体、TextKit 排版、图片和公式绘制基础来自本仓库原产品的纯笔记实现；已独立复制并移除 Agent 运行和插件页面渲染入口。公式资源保留原随附 KaTeX、Mermaid 等许可文件。新应用不链接原产品的执行目标或 Agent 核心。
