# 插入光标与输入体验验证

日期：2026-10-16。范围：用户明确确认的光标对齐、平滑移动和输入连续性增量。

## 改动

- 插入光标采用 2pt 细竖线，依据字号与字体基线垂直居中，不将行间距或额外重音留白全部计入高度；标题与正文分别跟随字号。
- 水平定位使用 AppKit 的原生 insertion rect，保留中英文混排、Emoji、双向文字和自动折行的定位语义；不修改输入法候选框坐标或原生选区。
- Core Animation 移动为 0.12 秒 ease-out，可从当前 presentation position 重定向；中文组词期间即时定位，停止操作 0.65 秒后开始闪烁；选区、失焦及非活动窗口隐藏光标。
- 编辑和样式更新期间暂时保持文档高度，待布局稳定后调整，避免长文末尾换行时短暂缩高造成滚动回跳。
- 空列表退出后抑制输入法立即回插的列表符；下一次键盘、鼠标或粘贴操作解除一次性保护。

测试进程的窗口不能可靠获得 key-window 状态，因此没有将其背景窗口截图当作可见光标证明；最终截图来自已构建并取得焦点的真实应用，而非离屏绘图。自动测试验证几何与输入行为，不能替代主观动画手感评估，也没有提供持续帧率或真实输入法候选窗的录屏证明。marked-text 自动化覆盖原生组合输入协议，第三方输入法实际选词与回插行为仍需在对应输入法中体验。

该增量不改变已有完整产品验收记录中的未覆盖项目，不宣告全部产品验收完成。

## 打字动画缺失修复（2026-10-16）

用户反馈打字没有动画。收敛复现路径为：原生 setMarkedText 组合输入 → insertText 提交中文 → Markdown 重新设置属性 → TextKit 修正 insertion rect。提交时已经启动的 travel 动画被最后一次非动画的布局坐标更新移除，造成直接跳到最终位置。英文稳态直输并非同样必现；首个过渡采样实验也受到前一个未结束动画干扰，稳定初始位置后再以中文提交路径复现，避免将实验准备问题当作根因。

修复：当坐标修正发生时，如果光标已有活动的 travel，接续其 presentation position 到修正后的终点；不因为 animated=false 的布局同步取消仍在进行的输入反馈。中文组词阶段仍移除 travel 并即时定位，选区和失焦仍隐藏。

新增回归测试通过实际 NativeEditor / NSTextView / NSTextStorage / CALayer 路径同时检查英文和中文提交，执行布局与重排后必须保留移动动画；25ms 时采样 presentation position，必须仍与终点不同。仅以测试窗口覆盖 isKeyWindow 属性，补偿 XCTest 进程不能可靠激活的限制，未替换编辑器、布局或动画。移除修复单行后，同一测试稳定失败（travel 为 nil）；恢复后通过。修复前输出见 `typing-regression-before.txt`，最终全套输出见 `typing-test-results.txt`：29 项通过，无失败。临时诊断日志已移除，应用重新打包。

## 中文组词阶段动画补齐（2026-10-16）

用户再次明确指出中文输入没有动画。本次修订取代先前“组词即时定位、不做移动插值”的视觉策略：组词、候选词变化和最终上屏的可见插入光标均使用平滑移动；原生文本、选区及输入法候选框仍即时定位，不因视觉动画延迟。

原实现显式在 hasMarkedText 时移除 travel 并强制 animated=false；同时将 marked text 内的候选词选中误当成普通文字选区，隐藏光标。现已移除组合输入的动画禁用，并允许组合输入内部选中时在候选词末端显示光标。setMarkedText、insertText 和 unmarkText 的同步操作期间合并中间布局/选区通知，完成后统一更新可见位置，避免先隐藏再出现使动画丢失。未修改 AppKit 的 firstRect、selectedRange 或输入法候选框坐标接口。

同一原生输入测试先在旧实现失败：`Chinese preedit typing must animate before candidate confirmation`。修复后对拼音预编辑、选中整段中文候选、最终提交均检查活动移动动画，并通过 presentation-layer 中途采样检查预编辑与提交的可见位置尚未到终点。真实 native 输入和 TextKit 负责正文变化，仅复用上次测试的 key-window 环境补偿。全套 29 项通过，日志见 `composition-before.txt` 和 `composition-test-results.txt`。最终应用已重新打包，保存当前临时笔记库内容后退出旧进程并重新启动更新版本。

此处验证组合输入协议及实际图层动画，不宣称对每个第三方输入法或系统候选窗做过专项验收。此前仅提交阶段的验证不能证明组词阶段具有动画，本节明确补足这一遗漏。

实际新版窗口补查：通过真实按键 n、i 得到带下划线的 `ni` 预编辑文本，独立光标在预编辑末端可见；随后 Esc 取消，原笔记正文恢复一致。该截图/状态检查证明真实输入法预编辑路径可用；动态中途位置的证明仍来自上述 presentation-layer 采样，没有据静态截图宣称帧率或主观手感通过。
