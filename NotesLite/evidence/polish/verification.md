# 资料库界面重做实测

2026-10-16；Apple M4 / macOS 27.0.1 / Debug 原生应用。确认范围见 `../../../design/notes-lite/visual-refinement.md`（从项目根目录查看该设计文件）。本记录独立于上一版完整验收，不将旧版截图当作本次效果。

## 实现

- 中性侧栏、轻白列表、统一的 52pt 顶栏及细分隔；移除重复的大标题块。侧栏默认 208pt，列表 280pt。
- 导航行 34pt；笔记标题加一行摘要，日期缩短；空摘要不留占位，跨文件夹时才显示文件夹信息。菜单仅在悬停/选中时出现。
- 文件夹树支持层级、展开旋转和子项短距离进出，按路径分段排序，防止相似目录名打断父子关系。
- 两条分隔线可拖动，并支持无障碍增减，持久化宽度。侧栏范围 180–280pt、列表 220–380pt；窄窗口约束至少保留 320pt 正文。
- 悬停 1pt 轻浮与背景变化，按压缩放；选中底板以 0.32s / bounce 0.18 弹簧滑移，面板 0.5s / bounce 0.20，搜索结果采用同一短距离过渡。
- 同一原生正文编辑器持续保留；自动保存引起的数据刷新不额外绑定列表排序动画。Metal 采用加权磨砂采样，减少背景文字的重影感，边缘半径适应窄装饰区域。

## 已验证

- `swift test`：26 项通过，含 19 项核心/语法、3 项树与分栏约束、4 项真实原生窗口/编辑器/Metal 管线测试。Swift Testing 的 0 项输出不替代 XCTest 数量。
- marked text 组合输入期间连续 3 次弹簧专注往返，检查同一编辑器实例、组合输入、选区、撤销重做与保存。
- 新版着色器在本机实际 Metal 设备上编译并成功建立渲染管线；实际窗口运行记录见 `metal-runtime.json`，回调间隔不等于 GPU 帧耗时。
- 原生应用实际打开独立 `/tmp/noteslite-polish-vault`，8 篇样例、嵌套文件夹；展开日常、进入随记、选择雨后的散步，结果与正文对应。正常与空摘要笔记均检查实际显示。
- 实际分别将两栏调整至 224pt / 296pt；退出并重启，原生窗口仍读回这两个宽度。此项通过无障碍增量操作完成。
- 实测发现隐藏顶栏仍抢占专注快捷键，已取消工具按钮重复注册，统一应用菜单；最终打包版再次验证同一快捷键可进入并返回三栏。
- 最终打包版实际输入“留白”缩至 1 项结果，Esc 关闭后恢复 8 项列表，正文重新成为第一响应者；隐藏查询和焦点返回问题已实测修正。
- `library.jpg`、`folder.jpg`、`focus.jpg`、`search.jpg` 来自真实原生窗口。`focus-states.mp4` 为按实际采样间隔合成的状态采样；首帧在指令后约 766ms，不能作为完整逐帧转场或持续帧率证据。原始采样时间见 `motion-timing.json`。
