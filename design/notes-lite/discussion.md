  - 专注模式：整页以笔记编辑为主，收起导航、列表和工具等界面干扰（已确认）。
  - 已确认：柔软流动 Metal 效果，首版 macOS 原生组合，实际流畅度纳入完整验收。

## 第二轮回答与原型

- 用户希望通过 hero-prototype 比较界面，而非仅依据文字描述选择布局。
- 动效选择第三种：轻盈、有弹性、有惯性与轻微回弹。具体强度、频率和适用操作仍需体验后校准，不能将此前推荐的克制风格当作用户选择。
- 编辑方式确认：直接写 Markdown，原地显示排版，并保留源码控制；原型暂用源码文本编辑示意，不代表正式编辑器能力。
- 平台范围尚未回答。用户关注 Swift 能否实现更丰富的漂亮动效；SwiftUI 的弹簧、阶段/关键帧动画、自定义转场和 Metal 特效均可作为候选技术能力，不能把 Swift 等同于只能简洁。
- 已创建 [临时交互原型](prototype/index.html)，同一路由 `?variant=A/B/C` 切换纸页写作、清晰资料库和按需导航；使用同一组内存示例，支持导航、搜索、切换笔记、新建和试写。
- 原型仅用于布局和动效讨论，Web 实现不代表选定正式技术栈。不操作真实笔记库。

## 最终确认与规格阶段

- 用户选择 B 清晰资料库，并要求能切换到整页笔记编辑的清净专注模式。
- 用户明确要求结合 Metal 实现复杂视觉效果；不再将是否采用 Metal 作为待决问题。
- 原型已补充完整专注状态：隐藏应用工具栏、导航、笔记列表、元信息和状态栏；保留标题和正文。右上角低显著度退出入口及 Esc 可返回，浏览器外部的方案选择条仍属于原型工具。
- 用户已回答 Q8「第二种」：柔软流动，包含浮层折射与边缘高光、短暂交互波纹、面板展开和收拢的轻微形变。没有据此将复杂纸张特效作为额外承诺。
- 用户已回答 Q9「可以」：首版 macOS，SwiftUI 界面、AppKit 文本编辑器与 Metal 特效组合；独立工程，保留原软件。
- 用户已确认完整验收：核心笔记功能、原软件不受影响、无 Agent 后台联动、原生 Metal 效果、动画流畅度及专注模式实际体验。
- 规格已写入独立设计上下文；项目未提供 issue tracker 配置且无 Git remote，因此尚未发布，也未创建远程 issue。

Agent 联动的去除是已确认要求，不再将是否去除作为待决问题。
