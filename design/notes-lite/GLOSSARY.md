# 独立笔记软件（暂名）

保留本地 Markdown 核心笔记能力的独立产品，与现有共笔产品分别演进。

## Language

**笔记库**：
用户管理的一组本地笔记及其图片、附件。
_Avoid_: Agent 工作区

**笔记**：
以本地 Markdown 文件保存的可编辑文档，可以包含指向其他笔记或附件的链接。
_Avoid_: 交互记录、会话

**原产品**：
当前已有的共笔软件，保留其现有版本及产品方向，与本次独立笔记软件区分。
_Avoid_: 待替换版本

**专注模式**：
隐藏导航、笔记列表和工具等界面干扰，以当前笔记的标题与正文占据编辑空间的写作状态。
_Avoid_: 隐藏侧栏


**资料库导航**：
按全部笔记、最近打开和层级文件夹组织笔记浏览范围的导航区域。
_Avoid_: Agent 工作区导航

**笔记列表**：
展示当前浏览范围内的笔记标题、摘要及必要信息，并标识正在编辑笔记的区域。
_Avoid_: 会话列表
