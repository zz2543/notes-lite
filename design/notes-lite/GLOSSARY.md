# 独立笔记软件（暂名）

保留本地 Markdown 核心笔记能力的独立产品，与现有共笔产品分别演进。

## Language

**笔记库**：
用户管理的一组本地笔记及其图片、附件。
_Avoid_: Agent 工作区

**笔记**：
以本地 Markdown 文件保存的可编辑文档，可以包含指向其他笔记或附件的链接。
_Avoid_: 交互记录、会话

**原产品**：
当前已有的共笔软件，保留其现有版本及产品方向，与本次独立笔记软件区分。
_Avoid_: 待替换版本

**专注模式**：
隐藏导航、笔记列表和工具等界面干扰，以当前笔记的标题与正文占据编辑空间的写作状态。
_Avoid_: 隐藏侧栏


**资料库导航**：
按全部笔记、最近打开和层级文件夹组织笔记浏览范围的导航区域。
_Avoid_: Agent 工作区导航

**笔记列表**：
展示当前浏览范围内的笔记标题、摘要及必要信息，并标识正在编辑笔记的区域。
_Avoid_: 会话列表

**插入光标**：
正文编辑时标示下一次文字插入位置的细竖线；存在文字选区时，输入会替换选区。
_Avoid_: 鼠标指针、选区边框

**文字选区**：
正文中被选中的一段连续文字，可以跨越多行、多个段落和块；它的高亮只贴合被选中的文字及块本身，而不铺满页面宽度。
_Avoid_: 选中块、整行选中

**单栏导航**：
文件夹与笔记共同呈现在一棵可展开层级树中的浏览方式；正文编辑区单独呈现。
_Avoid_: 单栏编辑、专注模式

**双栏导航**：
文件夹树与当前目录内容分别呈现在两栏中的浏览方式；正文编辑区单独呈现。
_Avoid_: 双栏编辑

**当前目录内容**：
当前浏览目录的直属子文件夹与直属笔记，不包含更深层目录中的笔记。
_Avoid_: 后代笔记汇总

**空间**：
由用户命名、围绕某一主题（如“健身”“雅思”）组织的入口，包含一个范围，并可以有一个空间主页。空间不属于任何文件夹。
_Avoid_: 文件夹主页、工作台、仪表盘、模式

**范围**：
空间所关联的一个、多个文件夹或整个笔记库；空间主页只能读取和写入范围内的笔记。
_Avoid_: 绑定目录、权限组

**空间主页**：
展示空间内进展并提供快捷记录的页面，数据全部来自范围内的记录表，自身不保存数据。
_Avoid_: 仪表盘、首页

**记录表**：
范围内笔记中以表头定义字段的 Markdown 表格，是空间主页读取和写入数据的唯一形式。
_Avoid_: 数据库、数据文件

**记录**：
记录表中的一行。
_Avoid_: 条目、数据点

**编写说明**：
留白随版本自动生成的说明文档，告诉 Agent 如何编写空间主页：可用的样式、组件和接口。
_Avoid_: 提示词、插件文档

**操作记录**：
空间主页对笔记做出的每一次写入的留痕，可逐条撤销，关闭应用后仍然保留。
_Avoid_: 历史版本、日志
