# 临时布局原型

问题：纸页写作、清晰资料库、按需导航三种结构，哪一种适合新的独立笔记软件？

运行：在仓库根目录执行 `python3 -m http.server 8766 --directory design/notes-lite/prototype --bind 127.0.0.1`，然后打开 http://127.0.0.1:8766/?variant=A 。也可直接打开 index.html。

底部切换 A/B/C；非编辑状态下左右箭头切换。支持搜索、切换示例、新建、编辑和专注模式。导航浮层使用可重定向的阻尼弹簧。所有笔记只存在内存，刷新重置；不访问真实笔记库。正文是 Markdown 源码编辑示意，不包含正式实时渲染器。

这是专门供设计比较的独立临时页面，原应用是原生 macOS 工程，没有可挂载的 Web 路由。原型不确定正式技术栈。选定后将保留原型到独立临时分支，并在设计记录中记录结论；当前尚无获选方案。
