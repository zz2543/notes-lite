# 以用户可定义的交互模式承载 AI 协作

2026-10-11 用户明确，共笔定位为通用的开放笔记产品，提供多种可切换的默认交互模式，并允许用户依据接口文档让 Agent 编写模块、创建模式或修改已有模式。交互过程及 Agent 的主动程度由模式定义；现有界面没有必须保留的组织方式，因此不以单一研究写作流程或现有三栏布局限定产品。这个决定把长期扩展性放在产品边界内，也要求后续设计明确模式能改变什么、模式之间如何切换，以及平台提供哪些共同能力。

第二轮用户进一步确认：模式可以同时定义工作区前端、交互方式和 Agent 行为；内置模组作为可选的复用能力，也允许自行实现；跨模式的界面和操作方式不强制一致。平台扩展能力的可组合性不等于统一界面规范；具体接口、运行状态和存储方案仍待后续访谈决定。

第四轮用户强调，系统页面也必须高度自适应，不能只是换皮。第五轮进一步确认：模式提供可复用的阶段页面，运行中的 Agent 也可以按当前需要临时生成新的交互界面，例如在学习过程中加入可操作的演示。因此扩展能力必须覆盖模式编写和模式运行两个阶段；具体运行环境与接口实现仍待工程设计。
