# 共笔

共笔是保留本地 Markdown、支持多种可自定义 AI 交互模式的开放笔记产品。这里只记录已经澄清的产品术语。

## Language

**交互模式**：
用户按任务选用的一种与 AI 协作的方式，包含可定制的工作区界面、交互过程和 Agent 行为。模式与资料独立，同一份资料可以用于不同模式，用户可以创建新模式或修改已有模式。
_Avoid_: 布局主题、模型选择

**默认模式**：
产品随附、可以直接使用或由用户进一步修改的交互模式。
_Avoid_: 唯一工作流、固定工作流

**内置模组**：
产品提供的可复用协作环节或界面组件，例如等待用户回答。模式作者可以直接使用，也可以自行实现相应体验。
_Avoid_: 强制流程、固定页面

**HTML 交互视图**：
以 HTML 呈现内容并提供交互的可选视图，可以由用户描述需求后让 Agent 按需生成。笔记不必同时具备 MD 和 HTML 两份文档，是否显示格式切换入口可以设置。
_Avoid_: 固定预览页

**交互记录**：
用户与 Agent 交流过程中产生的记录，像聊天历史一样保留，供用户回看此前的交流。同一条记录中切换交互模式时，可以承接已有交流历史。
_Avoid_: 交互模式、项目看板

**格式转换**：
用户向 Agent 描述需要的内容或展示风格，由 Agent 将 MD 文档转换为 HTML 文档，或将 HTML 文档转换为 MD 文档的过程。
_Avoid_: 默认双份生成、自动双向同步

**自适应学习模式**：
围绕用户提出的学习主题，通过问题判断当前理解、确定学习范围，再结合知识讲解与小测反馈推进学习的交互模式。可以参考此前同一主题的学习记录，也可以在学习过程中加入新生成的交互演示。
_Avoid_: 固定问答模板、苏格拉底学习模式

**学习记录**：
围绕学习主题保留的回答、小测表现与理解薄弱点等信息，可供后续学习参考。用户可以纠正此前判断或选择从头开始。
_Avoid_: 永久能力标签
